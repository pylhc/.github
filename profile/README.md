## 🔬 OMC3

**[OMC3](https://github.com/pylhc/omc3)** is our main framework for beam optics measurements and corrections in circular particle accelerators.

It provides tools for frequency analysis of turn-by-turn data, optics measurements, correction calculations, accelerator model creation and related analysis workflows.
